# Security

SubLedger has no network access and stores data only on the device, so the attack surface is small. If you still find a problem, please report it privately.

Use the Report a vulnerability button on the Security tab of this repository. Please do not open a public issue for security problems.

Include what you found, how to reproduce it, and the Android version you tested on. You will get a reply as soon as the author can manage it.

Only the latest release is supported.
